What does the kernel do?

The kernel moves across the image. At every position, corresponding values are multiplied and then added.

Feature = Σ(Input × Kernel)

Pooling

Why reduce the feature map?

Pooling keeps important information while reducing the number of values passed to later CNN layers.

Flatten

Why create a vector?

After convolution and pooling, CNN features are commonly converted into a one-dimensional representation for later processing.

3

4

Weighted sum

z = Σ(xᵢ × wᵢ) + b

Each input is multiplied by its connection weight. The products are added together with the neuron's bias.

Activation

a = f(z)

The weighted sum passes through the selected activation function.

Sigmoid

σ(z) = 1 / (1 + e⁻ᶻ)

Sigmoid converts the weighted sum into a value between 0 and 1.

Learn CNN

What happened inside the CNN?

Follow how an input matrix passes through convolution, feature extraction, pooling and flattening.

1

Input image

The image is represented as a matrix of numerical pixel values.

2

Kernel slides

A small filter moves across different regions of the input image.

3

Values multiply

Each input value is multiplied by the corresponding kernel value.

4

Feature map forms

The multiplication results are added together to produce one feature-map value.

5

Pooling reduces

Pooling reduces the feature map while retaining important information.

6

Flatten creates a vector

The pooled matrix is converted into a one-dimensional feature vector.

Convolution

y(i,j) = Σₘ Σₙ x(i+m,j+n) × k(m,n)

The input region and kernel are multiplied element by element, then all products are added.

Feature map size

O = floor((N + 2P − K) / S) + 1

N is input size, P is padding, K is kernel size, and S is stride.

Max pooling

y = max(x₁,x₂,...,xₙ)

The largest value inside each pooling region is retained.

Average pooling

y = (x₁ + x₂ + ... + xₙ) / n

Average pooling calculates the mean value inside each pooling region.

Flatten

Matrix → [x₁, x₂, x₃, ..., xₙ]

Flattening converts the final two-dimensional feature map into a one-dimensional vector.

CNN pipeline

Input → Conv → Pool → Flatten

These operations transform raw input pixels into extracted features.
