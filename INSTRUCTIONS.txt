AI MODEL PLAYGROUND — TWO-PAGE UPDATE

1. BEFORE replacing anything, rename your CURRENT:

   index.html

   to:

   playground.html

   Do not change the contents of that file. It already contains all of your current playgrounds and learning sections.

2. Copy these NEW files into the root of the project:

   index.html
   script.js
   page-split.css

3. Keep these exactly as they are:

   style.css
   models/neural-network.js
   models/cnn.js
   models/decision-tree.js
   models/knn.js
   and the rest of your existing model files/assets.

4. Final structure:

   ai-model-playground/
   ├── index.html              NEW short Home page
   ├── playground.html         your OLD index.html renamed
   ├── style.css               keep existing file
   ├── page-split.css          NEW layout/mobile overrides
   ├── script.js               NEW navigation logic
   ├── models/
   │   ├── neural-network.js
   │   ├── cnn.js
   │   ├── decision-tree.js
   │   └── knn.js
   └── ...

5. Result:

   Home menu:
   Home | Playground | Go Back to My Website

   Playground menu:
   Home | Playground | Go Back to My Website

   There is no Learn menu.

   Learning sections remain inside the Playground page below the selected model.

   Opening playground.html does NOT automatically open KNN, Neural Network, or any other model.

   It first displays:
   "Choose a model to start"

   with the available models visible as cards.

   On mobile, "Choose / Change Model" opens a full model drawer and the selected model name is shown in the button.
